BlowTorch 2 v2.2.0
• Copy widget: two fingers now select everything between them
• Interactive tutorial — a tutor who teaches buttons/aliases/triggers/timers and checks your work
• Chained aliases no longer lose your arguments; one broken alias no longer disables the rest
• A mistyped trigger pattern can no longer crash the editor or stop a profile loading
• A failed settings import no longer overwrites the profile you had
• No more freeze when leaving the game; server list no longer shows a world you left as connected
• mudstd.frame GMCP package for server-controlled frames
