The good BlowTorch client is back! Now more stable, with more functions.

This app connects you to a MUD: a multiplayer text game over telnet. Add a host and port, connect, and you are in.

If you don't know where to look for MUDs, try these sites:
<a href="https://www.mudstats.com/">MudStats</a>
<a href="https://www.mudverse.com/">MudVerse</a>
<a href="https://www.mudconnect.com/">The Mud Connector</a>

Menus, settings, and Help are in English. Daily play needs little of the toolkit; when you want more, open Help in the app or the <a href="https://github.com/Taracair/BlowTorch2/blob/main/docs/user-manual.md">user guide on GitHub</a>.

Everyday play (some options might need to be turned on):
• On-screen buttons that send commands
• Suggestions from the text on the screen
• Stay connected with the screen off; the notification shows how long you have been on
• Growable input bar, search in scrollback, two-finger copy
• ANSI colours, optional session log, in-app Help

When you want more:
• Eight-way swipe, hold, and accordion (MORE) on a button; swap a set with a loadset
• Telnet plus GMCP, MCP, MXP, MSDP, MSSP, MCCP, MTTS; ANSI, 256-colour, truecolour, OSC 8 links
• Triggers, aliases, timers, and Lua plugins
• Extra text windows, a chat drawer, tappable words
• HP bars, rings, and countdowns
• Mapper (experimental), speedwalks, per-world settings
• A trigger or timer can read a line aloud

No ads, no analytics, no BlowTorch cloud account. Connects only to hosts you add. The F-Droid build does not contact GitHub on start. Lua plugins run with the app's privileges, so only load ones you trust. "All files access" is optional — settings, backups, and logs can live in /BlowTorch/. You can refuse it and still play; import and export use the system file picker. <a href="https://github.com/Taracair/BlowTorch2/blob/main/docs/FDROID_README.md">Details</a>

Original BlowTorch: Daniel Block / Offset Null Entertainment (MIT). Unofficial fork and continuation. Back up your settings before upgrading.
